# RE:SCAM — Recovery Scam Investigation

เกมการเรียนรู้สำหรับนักศึกษา เรื่อง Recovery Scam / Refund Scam หรือการหลอกซ้ำหลังจากผู้เสียหายเสียเงินไปแล้ว

## Concept
ผู้เล่นรับบทเป็น Cyber Detective ช่วยนักศึกษาที่เสียเงินจากร้านปลอม และมีบุคคลใหม่ติดต่อมาอ้างว่าสามารถตามเงินคืนได้ ผู้เล่นต้องวิเคราะห์ข้อความ ค้นหา Red Flags ปกป้องข้อมูล และตัดสินใจว่าจะเชื่อหรือหยุดการหลอกซ้ำ

## Target Users
นักศึกษาและเยาวชนที่ใช้งานออนไลน์และการเงินดิจิทัล

## Learning Objectives
1. ระบุ Red Flags ของ Recovery Scam ได้อย่างน้อย 5 ข้อ
2. อธิบายความเสี่ยงของค่าดำเนินการล่วงหน้าได้
3. แยกการช่วยเหลือจริงออกจากการแอบอ้างได้ดีขึ้น
4. ไม่เปิดเผย OTP / PIN / Password ให้บุคคลอื่น
5. รู้แนวทางหยุดการโอน เก็บหลักฐาน ติดต่อธนาคาร และแจ้งช่องทางทางการ

## Gameplay
- Story-based investigation
- Mission Map
- Smartphone chat simulation
- Decision making
- Score / Money / Stress
- Evidence Board
- Red Flag Hunt mini-game
- Multiple endings
- Personalized Learning Report
- Replayability

## Scoring
คะแนนเต็ม 100 โดยเกิดจากการตัดสินใจในสถานการณ์และ Red Flag Hunt

- 90–100: SCAM DEFENDER
- 75–89: SMART DEFENDER
- 50–74: NEEDS PRACTICE
- 0–49: HIGH RISK

## AI Iteration
1. Prototype — เกมเลือกตอบ
2. Gameplay — เพิ่ม score, money, stress, mission map, endings
3. Learning Design — เพิ่ม feedback, evidence board, red flag hunt, report
4. Rubric Audit — เพิ่ม sources, ethics, accessibility, rubric alignment

## Ethics
- ไม่มีเงินจริง
- ไม่เชื่อมธนาคาร
- ไม่เก็บชื่อ อีเมล เลขบัญชี OTP หรือข้อมูลส่วนตัว
- ใช้ localStorage เฉพาะความคืบหน้าของเกม
